# Notes 3 

* What is a graphical user interface (GUI)?
  * A GUI lets users interact with a computer using icons, buttons, windows, and menus instead of typing commands.
  
* What is a desktop environment?
  * A desktop environment provides visual tools like icons, menus, and taskbars to help users interact with a computer.
  
* What is the command line interface (CLI)?
  * A CLI lets users interact with a computer by typing text commands instead of clicking icons or buttons.
  
* How do I access the command line interface (CLI)?
  * You can access the CLI by opening a terminal application or switching to a virtual console.

* What is a virtual console?
  * A virtual console is a text-based screen that lets users enter commands without using the graphical desktop.
* 
* What is a terminal emulator?
  * A terminal emulator is a program that lets users type and run commands in a window on the desktop.
  
* What is bash?
  * Bash is a shell that reads and runs commands typed by a user.
* What is the shell prompt?
  * The shell prompt is a symbol or text that shows the shell is ready for you to type a command.
### Definitions 
* **clear** - clears the terminal screen
* **echo** - displays text in the terminal 
* **date** - displays the current date and time 
* **free** - shows memory usage, used and available RAM
* **uname** - displays system information like OS and kernel
* **history** - shows previously typed commands
* **man** - opens the manual for a single command 
* **tldr** - displays simplified command explanations
* **cheat** - displays command examples and usage tips
* **hostname** - displays the computer's network name
* **df** - shows available and used disk space on file systems
* **du** - shows how much disk space files and directories use
* **figlet** - displays text in large, decorative ASCII letters
