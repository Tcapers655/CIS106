## Command Definitions 

1. **mkdir** command 
   1. **Definition** - the mkdir command is used to create a new directory or folder in linux 
   2. **Usage/Formula** 
      1. ```mkdir [directory_name]```
   3. **Example**
      1. ```mkdir Website``` - creates a folder/directory named "Website" 
   
2. **touch** command 
   1. **Definition** - the touch command creates an empty new file 
   2. **Usage/Formula**
      1. ```touch [file_name]```
   3. **Example**
      1. ``` touch index.html``` - creates an empty html file 

3. **rm** command 
   1. **Definition** - the rm command deletes files and folders 
   2. **Usage/Formula** 
      1. ```rm [file_name]```
   3. **Example**
      1. ```rm index.html``` - deletes the index.html file 

4.  **cp** command 
    1.  **Definition** - the cp command copies files or folders from one location to another while keeping the original file in its original location 
    2.  **Usage/Formula** 
        1.  ```cp [file/folder name] [destination]```
    3. **Example**
       1. ```cp Website Desktop/``` - copies the Website directory to desktop directory
   
 5. **mv** command 
    1. **Definition** - the mv command can move files and folders from one location to another and rename them 
    2. **Usage/Formula**
       1. ```mv [file_name] [new destination]```
    3. **Example**
       1. ```mv index.html Documents/website.html``` - moves the index.html file to the Documents directory while renaming it to website.html
