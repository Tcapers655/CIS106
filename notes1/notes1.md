# What is Markdown
Markdown is a markup language that allows for slight formatting options that are compatible for conversion to other file types. 

# What is Git? 
 Git is an open-source tool that allows programmers to keep track of version history and revert back to an older version of code if necessary. 

# What is Github?
 Github is a site that allows users to store and share their projects. 

# What is Slack? 
 Slack is a professional communication platform that allows different teams to share information and divide conversations into channels depending on the topic.
